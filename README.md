## 项目名称

Easy File，基于 Flet GUI 的文件资源管理器。



## ✨ 功能

\- 功能1：可供用户查看PC中有哪些文件（启动后，默认地址为当前用户桌面）

\- 功能2：可一键切换隐藏文件显示、隐藏

\- 其他功能正在不断完善中……



## 📦 运行环境

\- Python >= 3.15.2

\- 依赖清单：requirements.txt



## 🚀 项目部署

1\. 克隆项目

git clone https://github.com/xxxxxx/xxx.git

cd xxx

2\. 创建虚拟环境（Windows）

python -m venv venv

3\. 激活

\# cmd

venv\\Scripts\\activate

\# powershell

.\\venv\\Scripts\\Activate.ps1

4\. 安装依赖

pip install -r requirements.txt

5\. 运行

python main.py
